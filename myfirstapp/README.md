# Student Dashboard

A responsive student dashboard built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- Summary cards for courses, assignments, and progress
- Course cards with progress information
- Assignment list with due dates and completion status
- Filters for all, pending, and completed assignments
- Empty-state messages when a filter has no results
- Interactive hover effects and responsive layouts
- Accessible announcement of remaining assignments
